Entry for the [make.fun](https://make.fun) bounty
[One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee)
— one line, 200 characters max: a pickup line a vending machine would
use on a passing human.

## The line

> A thousand snacks spun through my coils and not one ever jammed — then you walked past, and now I'm stuck on you.

113 characters. The machine brags about its spotless record, then the
human walks past and the machine itself jams — on them. First-person
machine voice, coils and jamming from the machine's own world, and the
punch lands on the last words: "stuck on you" is both a jammed coil and
a crush.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, exactly the one line, no
trailing newline).
